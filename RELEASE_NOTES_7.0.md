# Release Notes — Fodd 7.0 Apple Experience (Build 13)

Fodd 7.0 membawa fitur social food diary yang sudah matang ke ekosistem Apple secara native.

## Highlights
- Home Screen Widget (small + medium).
- Live Activity & Dynamic Island untuk Makan Bareng.
- Remote Live Activity update melalui APNs backend.
- App Intents dan App Shortcuts untuk Siri/Shortcuts.
- Core Spotlight indexing untuk restoran, Food Moment, foodie, dan Dining Plan.
- SharePlay Group Activity untuk Dining Plan.
- Apple Maps Look Around preview + viewer pada restoran yang didukung.
- Apple Experience settings/status screen.
- App Group untuk main app + widget.
- Privacy Manifest main app + widget.
- Version 7.0, Build 13, backend 7.0.0.

Semua fitur 6.5 dan versi sebelumnya tetap dipertahankan.
